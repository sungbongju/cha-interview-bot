# RAG 분석 리포트 - 2026-05-05

## 1. 분석 목적

차의과학대학교 미래융합대학 전공소개봇의 답변 품질을 점검하기 위해 운영 중인 RAG 데이터를 확인했다. 교수님 피드백의 핵심은 전공별 유튜브 인터뷰 내용이 충분히 반영되어 있는지, 특정 전공에서 잘못된 답변이나 부정확한 표현이 나오는 이유가 무엇인지 확인하는 것이었다.

## 2. 운영 RAG 위치

현재 운영 RAG는 Middleton 서버의 finbot 서버에서 사용 중이다.

- 서버 경로: `/home/student04/finbot/server/data/`
- chunk 파일: `cha_rag_chunks.json`
- embedding 파일: `cha_rag_embeddings.json`
- 서버 프로세스: `finbot-server`

RAG 검색은 `bge-m3` 임베딩을 사용하고, 검색된 chunk를 Gemma 계열 모델에 전달해 답변을 생성하는 구조다.

## 3. 기존 RAG 상태

초기 확인 시 운영 RAG는 다음 상태였다.

- chunk 수: 82개
- embedding 수: 82개
- embedding dimension: 1024
- 전공 수: 11개 전공 모두 포함

다만 구조상 모든 유튜브 전사본을 그대로 넣은 것이 아니라, 전공별 핵심 내용을 요약한 Q&A chunk 위주로 구성되어 있었다.

특히 경영학은 기존 자료와 기본 RAG가 상대적으로 풍부했지만, 나머지 전공은 보통 전공별 4~6개 chunk 수준이었다. 이 때문에 대표 질문에는 답변이 가능하지만, 영상에서 언급된 세부 사례, 실습 방식, 자격증, 전공별 교수님 표현, 전공 간 시너지 같은 질문에는 답변이 얕아질 가능성이 있었다.

## 5. 발견된 주요 문제

### 5.1 전사본 전체 반영 부족

기존 RAG는 전공별 유튜브 전사본 전체를 세밀하게 chunk화한 구조가 아니었다. 전공별 대표 Q&A를 압축한 형태였기 때문에, 신입생이 구체적인 질문을 했을 때 답변 근거가 부족할 수 있었다.

예를 들어 다음과 같은 질문은 기존 RAG만으로는 답변이 약해질 수 있었다.

- 스포츠의학에서 해부학은 얼마나 중요한가요?
- 스포츠의학 실습은 몇 번 가나요?
- 미디어커뮤니케이션학은 내향적인 학생도 괜찮나요?
- 시스템생명과학 연구실 인턴은 어떻게 컨택하나요?
- 세포유전자재생의학과 시스템생명과학은 어떤 시너지가 있나요?

### 5.2 스포츠의학 RAG 표현 문제

스포츠의학 chunk에 `신경 치료 이후`라는 표현이 있었다. 정성률 교수님 피드백에 따라 이 표현은 제거가 필요했다. 운영 RAG와 프론트 프록시 후처리 모두에서 해당 표현이 나오지 않도록 조치했다.

### 5.3 일부 전사 오류 또는 오타

세포유전자재생의학 chunk에서 다음과 같은 전사 오류 또는 오타가 발견되었다.

- `활생학·신음 실습`
- `기업 단방`

이는 각각 다음처럼 수정했다.

- `발생학·생식의학 관련 실습`
- `기업 탐방`

## 10. 남은 한계와 다음 작업

이번 작업은 사용자가 제공한 유튜브 전사본을 바탕으로 전공별 상세 chunk를 보강한 것이다. 다만 아직 완전한 의미의 “전사본 전체 원문 기반 RAG”는 아니다. 현재 상태는 기존 요약형 RAG에서 한 단계 발전한 상세 Q&A형 RAG다.

## 11. 교수님께 보고 가능한 요약

이번에 전사본을 기준으로 전공별 상세 chunk 38개를 추가하여 운영 RAG를 82개에서 120개로 확장했습니다. 스포츠의학의 금지 표현과 세포유전자재생의학의 오타도 수정했고, 실제 API 테스트에서 새 RAG 내용이 답변에 반영되는 것을 확인했습니다.
