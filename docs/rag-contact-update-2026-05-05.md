## 5. TTS 정책

화면(`reply`)에는 URL·전화·이메일을 그대로 표시하지만, **음성(`ttsReply`)은 "학과 홈페이지", "학과 사무실", "학교 대표 번호", "학과 이메일"** 같은 자연어로 치환한다 — 음성으로 URL/전화번호를 한자 한자 읽지 않도록.

치환은 Vercel `api/chat.js`의 `sanitizeResponse()` 안에서 처리한다 (운영 미들턴 코드는 건드리지 않음).

## 6. 미들턴 서버 적용 절차 (사용자 수동 실행)

외부 SSH 포트가 모두 차단되어 있어 학교 내부에서 직접 실행해야 한다.

```bash
# 1. 미들턴 서버에 접속 (학교 내부망)
ssh student04@<미들턴 내부 호스트>

# 2. 작업 디렉토리로 이동
cd /home/student04/finbot/server

# 3. JSONL 파일을 서버로 복사 (scp / rsync / 직접 vi 붙여넣기 등)
#    예: 이 레포 server/contact_chunks_2026-05-05.jsonl 을
#    /home/student04/finbot/server/contact_chunks.jsonl 로 업로드

# 4. 추가 (자동 백업 + 임베딩 생성 + 추가)
node add_to_rag.js contact_chunks.jsonl

# 5. 검증 (chunk 수 120 → 131, 마지막 ID = ch-131)
node verify_rag_update_2026-05-05.js
```

`add_to_rag.js`는 자동으로 `cha_rag_chunks.json.bak.<timestamp>` / `cha_rag_embeddings.json.bak.<timestamp>` 백업을 만든 뒤 추가한다 — 만약 문제가 생기면 그 백업 파일로 롤백 가능하다.
