# RAG 상세 보강 초안 - 2026-05-05

## 목적

현재 운영 RAG는 11개 전공을 모두 포함하지만, 경영학을 제외한 전공들은 유튜브 전사본 전체가 아니라 핵심 요약 Q&A chunk 위주로 구성되어 있다. 교수님 피드백과 신입생 테스트 질문에 대응하려면 전공별 영상 속 구체 정보, 예시, 교수님 표현, 진로·실습·자격증·융합전공 설명을 더 촘촘히 추가해야 한다.

## 적용 방식

- 기존 `ch-001~ch-082`는 우선 유지한다.
- 전사본 기반 상세 보강 chunk를 `ch-083`부터 추가한다.
- 기존 chunk 안의 명백한 오타와 금지 표현은 별도 수정한다.
- 서버 반영 전에는 운영 RAG와 embedding 파일을 백업한다.

- 초안 파일: `server/detailed_chunks_2026-05-05.jsonl`
- 형식: 기존 RAG 추가 스크립트와 동일한 JSONL
- 필드: `id`, `section`, `question`, `answer`, `keywords`, `embedding_text`
